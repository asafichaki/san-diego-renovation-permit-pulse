Methodology

Careful by design.

01

Filter

Use 2026 issued Building Permit and Combination Building Permit records with explicit residential evidence.

02

Classify

Assign keyword categories only when public text explicitly names ADU, kitchen, bathroom, roofing, renovation or remodeling.

03

Deduplicate

Count a City project once per category, using its earliest matching issue date.

04

Protect

Publish aggregates only. Never republish holder names, addresses, coordinates or project-level scope text.

Read this metric correctly. “Elapsed calendar days” runs from the City project-create date to the first matching issued approval. It is not staff processing time, construction duration, or a promise of how long a new application will take.
